前缀和数组

2026-03-24 · 约 6 分钟 · 1,842 字
#Java算法#前缀和

前缀和是那种「一旦看懂就再也不会忘」的技巧，但真正写对边界的人在初学者里并不多。这篇文章从一个最朴素的区间求和问题出发，把它推到二维。

为什么需要前缀和

给定一个长度为 n 的数组，需要回答 m 次「区间 [l, r] 的元素和」。最直接的做法是每次遍历一遍，单次 O(n)，总复杂度 O(nm)。

当 n = m = 10⁵ 时，这个做法会跑到 10¹⁰ 次运算——远超评测机一秒的量级。而前缀和把每次询问降到 O(1)。

核心思想：用一次 O(n) 的预处理，换取此后每一次查询的常数时间。

一维前缀和

定义 pre[i] 表示前 i 个元素的和（下标从 1 开始，pre[0] = 0）。

// 构造：O(n)
for (int i = 1; i <= n; i++)
    pre[i] = pre[i - 1] + a[i];

// 查询 [l, r]：O(1)
int sum = pre[r] - pre[l - 1];

注意 l - 1 这一项：如果让下标从 0 开始，就要额外处理 l = 0 的越界。这也是为什么几乎所有模板都从 1 开始存。

构造方式

构造时一定要把 pre[0] 置为 0，否则前缀和会残留上一组测试数据。

二维前缀和

子矩阵求和的容斥公式是：

sum = pre[x2][y2] − pre[x1−1][y2] − pre[x2][y1−1] + pre[x1−1][y1−1]

做法预处理单次查询适用
暴力O(1)O(n)查询极少
前缀和O(n)O(1)静态数组
树状数组O(n log n)O(log n)带修改

复杂度与边界

  • 前缀和只能处理静态数组，一旦有修改就要换数据结构；
  • 数值可能溢出 int，累加时要开 long；
  • 二维前缀和的数组要比原矩阵多开一圈。
